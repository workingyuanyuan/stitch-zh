## 查詢快捷鍵

隨時按 `?` 會開啟完整的快捷鍵清單。清單依類別整理，並依作業系統顯示對應的修飾鍵：Mac 是 `⌘`，Windows 與 Linux 是 `Ctrl`。

## 快捷鍵

### 編輯

| 動作 | Mac | Windows / Linux |
| --- | --- | --- |
| 復原（Undo） | `⌘Z` | `Ctrl+Z` |
| 重做（Redo） | `⌘⇧Z` | `Ctrl+Shift+Z` |
| 複製（Copy） | `⌘C` | `Ctrl+C` |
| 貼上（Paste） | `⌘V` | `Ctrl+V` |
| 為選取的畫面建立副本（Duplicate） | `⌘D` | `Ctrl+D` |
| 刪除（Delete） | `Backspace` 或 `Delete` | `Backspace` 或 `Delete` |
| 全選（Select All） | `⌘A` | `Ctrl+A` |

### 畫布工具

| 工具 | 按鍵 | 用途 |
| --- | --- | --- |
| 選取（Select） | `V` | 預設工具，選取與移動畫面 |
| 平移（Pan） | `H` | 拖曳以移動畫布 |
| 縮放（Zoom） | `Z` | 點一下放大，按住 `Alt` 再點一下縮小，拖曳則放大到框選的區域 |

### 檢視

| 動作 | Mac | Windows / Linux |
| --- | --- | --- |
| 放大（Zoom In） | `+`、`=` 或 `⌘=` | `+`、`=` 或 `Ctrl+=` |
| 縮小（Zoom Out） | `-` 或 `⌘-` | `-` 或 `Ctrl+-` |
| 顯示全部內容（Fit to View） | `0` 或 `⌘1` | `0` 或 `Ctrl+1` |

### 專案

| 動作 | Mac | Windows / Linux |
| --- | --- | --- |
| 儲存（Save） | `⌘S` | `Ctrl+S` |
| 下載選取的畫面 | `⇧D` | `Shift+D` |

### 切換畫面

| 動作 | Mac | Windows / Linux |
| --- | --- | --- |
| 下一個畫面 | `⌘→` | `Ctrl+→` |
| 上一個畫面 | `⌘←` | `Ctrl+←` |

畫面的順序是由左到右、由上到下，和閱讀一頁文字的順序相同。用這兩組快捷鍵切換時，Stitch 會選取目標畫面，縮放到剛好顯示整個畫面，並把它置中。

在畫布上迷路時，按 `⌘←` 或 `Ctrl+←` 跳到最近的畫面，或按 `0` 縮小到看得見整個專案。

## Command Palette

按 `⌘K`（Mac）或 `Ctrl+K`（Windows 與 Linux）開啟 Command Palette，可以搜尋 Stitch 裡目前可用的所有動作。

- 清單依目前的情境篩選，和目前選取項目有關的指令排在最前面。
- 輸入文字即時篩選。
- 用方向鍵移動，按 `Enter` 執行。
- 每個指令的右側顯示它的快捷鍵。

記得想做什麼、但忘了功能在哪個選單時，輸入幾個字母就能找到。產生新的畫面也可以從這裡執行。

## 底部工具列的三種工具

底部工具列有選取、平移、縮放三種工具，各自改變滑鼠在畫布上的作用。

| 工具 | 滑鼠操作 |
| --- | --- |
| 選取 `V` | 點一下選取畫面；拖曳移動畫面；在空白處拖曳拉出選取框 |
| 平移 `H` | 在任何地方拖曳以移動畫布，不會誤選或誤移畫面 |
| 縮放 `Z` | 點一下以滑鼠所在位置為中心放大；按住 `Alt` 再點一下縮小；拖曳畫出矩形，縮放到剛好顯示該區域；按 `Escape` 取消進行中的框選 |

### 按住以暫時切換

| 按法 | 效果 |
| --- | --- |
| 按一下 `V`、`H` 或 `Z` | 切換到該工具，直到再切換為止 |
| 按住 `Space` | 在任何工具下暫時變成平移；放開後回到原本的工具 |
| 按住 `Z` | 暫時變成縮放；放開後回到原本的工具 |

例如平常停在選取工具，需要移動畫布時按住 `Space` 拖曳，放開後繼續選取與編輯。

### 目前工具的提示

使用中的工具在底部工具列會標示出來，暫時切換時也一樣。游標也會跟著改變：

| 工具 | 游標 |
| --- | --- |
| 選取 | 箭頭 |
| 平移 | 手掌：待命時張開，拖曳時握拳 |
| 縮放 | 放大鏡：放大時顯示 `+`，按住 `Alt` 縮小時顯示 `-` |

## 組合使用

- 選取多個畫面後按 `⇧D`（`Shift+D`），一次全部下載。
- 在縮放工具下按住 `Space`，可以暫時平移，不必切換工具。
- 按 `⌘A`（`Ctrl+A`）全選所有畫面，再按 `⌘D`（`Ctrl+D`），為整個專案的版面建立副本。
